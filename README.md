# 📊 Bet Calculator (Калькулятор ставок)

Простое и легкое веб-приложение для отслеживания баланса, коэффициентов и результатов ставок. Работает прямо в браузере и сохраняет все данные локально.

## ✨ Возможности
- 💰 Учет начального баланса и автоматический расчет итоговой прибыли/убытка.
- ➕ Быстрое добавление ставок с указанием суммы и коэффициента.
- ✅❌ Удобная отметка результатов (Выиграла / Проиграла / В процессе).
- 💾 Автосохранение данных в `localStorage` (данные не пропадут при закрытии вкладки).
- 📱 Адаптивный дизайн (отлично работает на телефонах и ПК).
- 🌙 Темная тема по умолчанию.

## 🛠️ Технологии
- HTML5
- CSS3 (CSS Variables, Flexbox)
- Vanilla JavaScript (ES6+)

## 🚀 Как запустить
1. Клонируйте репозиторий:
```bash
   git clone https://github.com/ВАШ_НИК/bet-calculator.git
```
2. Откройте файл `index.html` в любом современном браузере.

## 🌐 Деплой (GitHub Pages)
Этот проект готов к развертыванию на GitHub Pages:
1. Зайдите в **Settings** (Настройки) репозитория.
2. Перейдите в раздел **Pages** в левом меню.
3. В разделе **Branch** выберите `main` (или `master`) и папку `/ (root)`.
4. Нажмите **Save**. Через минуту ваш калькулятор будет доступен по ссылке вида: `https://ВАШ_НИК.github.io/bet-calculator/`
